# Tachimi

Tachimi は、 [TACHIE](https://tachie.net) 専用の立ち絵管理アプリです。

## リポジトリの構成

- `tachimi-aviutl2`：AviUtl2 プラグイン。
- `tachimi-cli`：コマンドライン。主なロジックはここに含まれています。
- `tachimi-common`：共通ライブラリ。主にスキーマが含まれています。
- `tachimi-docs`：ドキュメント。
- `tachimi-gui`：GUI アプリ。
- `tachimi-server`：tachie.net のデータを取得するためのプロキシ。
